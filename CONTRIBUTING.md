# Contributing to Crystal View Chatbot (n8n workflow)

Thanks for your interest in contributing! This project exports an n8n workflow that demonstrates a Telegram-based AI assistant integrated with a vector knowledge base and calendar booking.

Guidelines
- Please do not add or commit any credentials, tokens, API keys, or private files.
- Use placeholders for any credential references (for example, TELEGRAM_API_CREDENTIAL_ID_PLACEHOLDER).
- Keep workflow exports sanitized. If you add an updated workflow export, name it `crystal_view_chatbot.sanitized.json`.
- When proposing changes to prompts or logic, include reasoning and expected behavior.
- For code or docs changes: open a pull request with a clear description and, where relevant, example test steps.

How to contribute
1. Fork the repository.
2. Create a branch for your change: `git checkout -b feature/your-change`.
3. Make changes.
4. Commit and push your branch.
5. Open a Pull Request describing your change and why it’s needed.

Security & privacy
- Never include real credentials in commits.
- If you discover any accidentally committed secrets in the repository history, report them immediately and rotate the secrets.

Contact
- For questions or larger features, open an issue first so we can discuss the approach.
